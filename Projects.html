1.Swirl Project

The Swirl project is an independent website made with HTML and CSS that must be original and creative. It needs three content pages, a title, favicon, images, colors, and at least three special features like links, hover effects, lists, or a footer. The site must be hosted on GitHub Pages, and once everyone submits, the class earns a food grant.

2. Linking pages

This assignment teaches students how to create and use links while learning good website navigation practices. Students explore early web pages to understand how links shaped the web, practice building their own links in Web Lab, and reflect on their project progress and goals.

3. CSS classes

This assignment teaches students to use CSS classes to style specific elements on a webpage, allowing more control over a pages appearance. Students will explore existing classes, modify them, and create their own to make their pages more flexible, organized, and visually appealing, while learning how these skills can enhance the design of their team websites.

5. Styling Text with CSS

This assignment introduces CSS as a way to style elements on a webpage. Students learn the basics of CSS rule-sets and explore properties that affect text, then apply their own styles to an HTML page about Guinness World Record holders. Optional activities allow them to experiment with additional CSS properties to further customize their page.

6. Using images

This lesson introduces images in HTML, which are self-closing tags that use attributes instead of surrounding content. Students learn to add images to their webpages with the tag, cite sources properly, and consider the ethical use of images, including intellectual property issues.

7. Adding Style to a Webpage

In this mini-project, students plan and style a webpage for a user using Web Lab and the Problem Solving Process. They submit a Project Guide with active links to their webpage and peer review, making sure sharing permissions are set correctly.

8. Organizing Content with Flexbox

This assignment teaches students how to organize web pages using div tags and apply Flexbox styling to control alignment, spacing, and layout. By practicing these skills, students learn how to structure content clearly and create responsive, well-designed web pages.

9. CSS Pseudo-classes

This lesson introduces students to CSS pseudo-classes and how they enhance web page interactivity and style. Students explore and practice using pseudo-classes such as link, visited, hover, and active to change how elements look in different states and improve the user experience on websites.

10. Styling Elements with CSS

This lesson continues teaching CSS by focusing on styling non-text elements. Students start by exploring a “Desserts of the World” website, modifying existing styles and adding their own. Then, they apply these new CSS properties to customize and enhance their personal websites.
